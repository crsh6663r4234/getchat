# Archived documents

These files are historical. They are internal plans, prompts, audits and one-off reports written while GhostChat 4.0 was being built (October and November 2026). They describe the state of the code at the time they were written, are no longer updated and may contain statements that are no longer true. They are kept for reference only.

For the current behaviour of GhostChat, read the documents in [`docs/`](..) and the [README](../../README.md).

| `ZERO_TRUST_AUDIT_BLUEPRINT.md` | Plan for that security audit |
| `SECURITY_REQUIREMENTS.md`, `SECURITY_INTERFACES.md`, `SECURITY_ACCEPTANCE_MATRIX.md`, `security-evidence.json` | Security requirements, interface inventory and evidence snapshot of 4.0.44 |
