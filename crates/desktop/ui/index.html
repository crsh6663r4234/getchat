PREFERENCES

Settings

Remote servers must use HTTPS and trust the GhostChat desktop origin. Session tokens are stored in Windows Credential Manager.

Notifications

GhostChat can show Windows notifications for friend requests, calls, and messages while it is running.

Voice and screen sharing

WebRTC sends live media directly between callers when possible. The default public STUN service and the person you call may see your network address. Relay-only mode needs a TURN server configured by the server owner. Screen sharing always uses the system picker so you choose what to share.
