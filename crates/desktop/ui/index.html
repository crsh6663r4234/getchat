Safety and reporting

Blocking removes the friendship and stops new direct messages and calls. Existing chat history stays available. Reports are sent to and stored by this server, and its operator can read them. Only the reason and details you enter are included; chat messages and attachments are never attached automatically. GhostChat has no moderation console or guaranteed response time.

Voice and screen sharing

Calls and screen sharing always use the server's authenticated TURN relay. GhostChat never falls back to a direct connection, so the person you call cannot see your network address. Calls can still be joined muted if no microphone is available.
