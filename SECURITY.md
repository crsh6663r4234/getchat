# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately
through GitHub's **Report a vulnerability** button on this repository's
Security tab. Include the affected version, steps to reproduce, and the impact
as you understand it.

We aim to acknowledge a report within a few days and to publish a fix in a
new release. Details of the design, the threat model and what is and is not
protected are in [docs/SECURITY.md](docs/SECURITY.md).
